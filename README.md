# Better Quest 3 Physics Sandbox

An original Unity starter game for standalone Meta Quest 3. It includes:
- A generated playable sandbox scene
- XR Origin + controller/hand-ready interaction architecture
- Physics grabbable objects
- Spawnable cubes, spheres, capsules and platforms
- In-world menu
- Simple locomotion/turning hooks
- Performance guard
- Quest Android/ARM64/IL2CPP build script
- Codemagic workflow

This does not contain SlapLab proprietary source, assets, or branding.

IMPORTANT:
The project generates the scene at runtime so it does not depend on proprietary or unavailable prefabs.
For full tracked hands, install/configure Unity OpenXR + Meta XR packages in Unity Package Manager.
The included input layer works with keyboard fallback in Editor and is structured for XR input integration.

Recommended Unity:
6000.0.66f2 or later / Unity 6.1+

Meta's current documentation recommends Unity OpenXR for new Quest projects and the Meta Quest build platform.
